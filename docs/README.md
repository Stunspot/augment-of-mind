# MIND project site

This directory is the static GitHub Pages source for **MIND by Collaborative Dynamics**.

- `index.html` contains the semantic, text-first landing page.
- `style.css` contains responsive and accessible presentation rules.
- `assets/mind-hero.png` is a generated 1600×900 PNG artwork stored in the repository.
- `.nojekyll` tells GitHub Pages to serve the files directly.

The site intentionally uses no JavaScript, framework, webfont download, tracking script, or coded SVG illustration. Product claims are bounded to the public `1.0.0` contest package and its checked-in Faculty registry.
