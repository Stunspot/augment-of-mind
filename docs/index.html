Capabilities and limits · Use MIND

Arm's Reach

Installed should not mean forgotten.

MIND can compile a local semantic neighborhood of potentially relevant capabilities from the active reminder estate. The prompt hook handles bounded pre-turn recall when possible; the direct local query path remains available for explicit contextual association.

A reminder is not a ranking, recommendation, activation, installation check, health check, permission, or authority grant. Nova or another host agent still decides what actually belongs in the work.

Current public estate: twenty standalone capabilities.

One integrator, sixteen Faculties, Capability Promotion, Software Verification, and Verification Reviewer. The profile is structurally checked; broader behavioral qualification and fresh-host delivery remain separate claims.

Verification boundary · Package reference

Recovery

Preserve the symptom before inventing the repair.

Keep the exact request, host, operating system, package version, and full error. Distinguish installation, discovery, hook trust, database state, reminder delivery, and model behavior before changing anything.

Plugin missing

Confirm the intended marketplace or extracted package, enable MIND, and start a new task.

Faculty missing

Record the exact discovered handles. A file on disk does not prove host discovery.

Reminder unavailable

Inspect the trusted hook bytes, Python environment, database path, and local runtime. MIND can still use capabilities the host exposes.
