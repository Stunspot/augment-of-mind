Install

From repository to a new task.

MIND installs through the pinned Collaborative Dynamics: MIND marketplace. Installation makes the Faculty skills discoverable; it does not install the optional Python Core or grant new tool authority.

  1. 1

    Add the released marketplace

    codex plugin marketplace add Stunspot/augment-of-mind --ref v1.0.0
  2. 2

    Install MIND

    Open /plugins in Codex CLI, or Plugins in the ChatGPT desktop app. Choose Collaborative Dynamics: MIND, then install and enable MIND.

  3. 3

    Start a new task

    Installed skills are loaded at the new-task boundary. Confirm that $augment-of-mind is available before diagnosing its behavior.

Associative disclosure

Arm's Reach remembers sideways.

Optional MIND Core can place a compact semantic neighborhood of capability handles within reach: exact vector-radius neighbors, exhaustive lexical matches, and explicit one-hop bridges or false-friend boundaries.

It is a reminder field, not a “top ten tools” list. Proximity does not establish fitness, selection, activation, health, permission, or action authority. The model still judges what—if anything—deserves to be opened.

Codex boundary: H0/query-capable.

The plugin does not automatically observe a turn or inject the field before reasoning. A generic host can integrate the portable envelope, but H1 requires observed event ingest, compilation, correlation, and pre-turn delivery.

The Faculty map

Distinct custody. Coherent synthesis.

Call the integrator when several transformations must contribute. Call one Faculty directly when one bounded transformation owns the work.

Govern and persist

  • Executive FunctionMission phase, acceptance, commitments, stops, recovery, and closure.
  • Capability ConductorSelection, sequence, handoffs, coalition shape, and merge custody.
  • Cognitive ContinuityDurable scoped state, provenance, correction, resumption, and forgetting.
  • Agent StrivingAuthorized long-horizon pursuit across interruption and recoverable failure.
  • Agent DreamingExplicitly authorized replay, perturbation, rehearsal, and incubation.

Understand and evaluate

  • SensemakingModels of actors, forces, causes, constraints, feedback, scale, and time.
  • Epistemic RegulationClaim state, warrant, confidence, contradictions, and revision conditions.
  • Measurement IntelligenceConstructs, baselines, measures, proxies, thresholds, and confounds.
  • Decision IntelligenceCriteria, options, trade-offs, reversibility, consequences, and recommendation.
  • Deliberative IntelligenceStakeholders, interests, decision rights, consent, and convergence.

Create, express, and act

  • Creative SynthesisDifferentiated candidates, analogies, constraints, exceptions, and reframings.
  • Aesthetic IntelligenceGestalt, affinity, compositional relations, taste calibration, and bearings.
  • KairosTruthful timing, voice, tone, channel, form, and rhetorical repair.
  • Prosocial InfluenceChoice-preserving change through reasons, supports, and informed refusal.
  • Instrumental AgencyAuthorized action choreography, state checks, rollback, and truthful disposition.

Recovery

HOL' UP before the workaround grows antlers.

Preserve the exact failure, identify the boundary it reached, determine why the cause existed, change one premise-bearing thing, then retest. An absent model, bad ref, workspace denial, and product defect are not four flavors of “try harder.”

Marketplace missing

Run codex plugin marketplace list, confirm the source and ref, then restart the supported host.

Faculty missing

Confirm the plugin is installed and enabled, then start a new task before judging discovery.

Core unavailable

Check Python, the exact wheel, database path, active snapshot, and session capability. Core will not invent a substitute.

Follow symptom-first troubleshooting · Get support

Privacy

No telemetry stowaway.

The plugin is local files: no tracker, analytics client, credential, or hosted MIND service. Optional Core writes only to the database path supplied by its caller and does not persist raw reminder anchors or field bodies.

Security

Host controls still control.

MIND cannot enlarge a sandbox, approval policy, account scope, or tool grant. Private reports belong in GitHub's vulnerability channel, not a public issue with the keys helpfully attached.
