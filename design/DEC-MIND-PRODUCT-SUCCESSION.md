# DEC-MIND-PRODUCT-SUCCESSION

State: Accepted and governing for the current branch

Decision date: 2026-09-04

Authority: stunspot, Nova product owner

The standalone “Augment of MIND” product lane is superseded. MIND is Nova's edition-invariant cognitive architecture, not a separate customer product, alternate persona, or optional cognitive upgrade. Every Nova edition is expected to contain the same basic mind beneath one governing Nova front door.

This repository remains in service as source-lineage and legacy-compatibility custody. Tags, published releases, built packages, checksums, and verification receipts remain immutable historical evidence. The 2.1.7 plugin is not silently redefined as the complete current Nova substrate: it contains sixteen Faculties and the legacy Arm's Reach/Capability Promotion/TestForge arrangement, and it predates Strategic Intelligence and the current Model Agnosticism/Trellis implementation.

No new standalone MIND release or customer installation should be produced from this branch. The present build and verification machinery is retained so historical artifacts stay reproducible and inspectable. A later authorized architecture pass may establish this repository or a successor as the edition-neutral component source consumed by all Nova editions; its component version, export boundary, and deterministic assembly rules remain pending.

The developer host still uses the enabled 2.1.7 prompt-submit hook for Arm's Reach. Do not disable, uninstall, delete, or archive that compatibility installation until a Nova-owned replacement adapter is constructed, qualified, installed, and observed. This decision does not publish a retirement notice, alter a website or storefront, delete artifacts, rewrite history, or authorize any destructive host change.
