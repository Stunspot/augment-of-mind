# MIND by Collaborative Dynamics

MIND is one integrator coordinating fifteen focused cognitive Faculties. This is the clean standalone public edition shipped in the Nova + MIND OpenAI Build Week release.

The repository contains only the curated contest package, with a fresh public history. The private development repository and its history are intentionally excluded.

- Contest source: [Nova the Optimal AI + MIND](https://github.com/Stunspot/nova-the-optimal-ai-mind/tree/e42dd11646bc548b9ac29d6f700370365ee68986/plugins/augment-of-mind)
- Contest version: `1.0.0`
- License: MIT

This package includes the Codex plugin manifest, the MIND integrator, and all fifteen Faculties.
