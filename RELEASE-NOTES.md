# Release notes

## MIND plugin 1.0.0

This is the first complete standalone public release of MIND by Collaborative
Dynamics.

### Included

- one adaptive MIND integrator;
- sixteen separately owned cognitive Faculties, including Agentic Eros;
- a Codex plugin manifest and Git-backed/local marketplace entry;
- customer installation, first-use, normal-use, recovery, privacy, security,
  support, and compatibility documentation;
- square icon, 16:9 hero, and 4:5 capability-card artwork;
- deterministic release manifest, archive verifier, and SHA-256 receipts;
- optional MIND Core `0.2.0` wheel;
- authored sixteen-Faculty cards, a behavior-qualified qwen3-embedding profile,
  a complete immutable index, and an explicit H0 query adapter.

### MIND Core 0.2.0

Core adds the persona-neutral SQLite metadata foundation and explicit
Associative Reminder Field:

- stable capability and provider identity without name collapse;
- independent custody, distribution, host-presence, runtime-use, fitness, and
  governance observations;
- immutable capability-card and associative-index generations;
- exact cosine-radius membership, exhaustive matching for caller-supplied
  lexical hints, typed one-hop bridges, and false-friend boundaries;
- private filtering before comparison, counts, errors, or diagnostics;
- canonical and compact fields with identical membership;
- a byte-bound portable delivery envelope tested against Exoframe's transient
  pre-sampling construction seam.

### Evidence ceiling

Codex support is H0/query-capable. The plugin does not automatically observe a
turn or inject a reminder field before reasoning. No third-party capability estate, bundled model weights, Claude distribution,
public-directory listing, or live H1
provider receipt is bundled or claimed.

### Upgrade note

The plugin remains `1.0.0`; the optional Core's `0.2.0` version does not
replace or renumber it. The customer release tag is `v1.0.0`.
